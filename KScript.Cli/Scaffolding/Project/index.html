Welcome to {{ title }}

This page is rendered by KScript on each request (today is { @today()->format(pattern: 'd MMMM yyyy') }). Edit index.html and refresh.

The Tasks page is a small app: its rules are in lib/tasks.ks.xml{{#if desktop}}, and desktop.ks.xml shows the same app in a desktop window{{/if}}.

Next steps

  • Add a page: kscript make page contact
  • Add a component: kscript make component Hero
  • Run the tests: kscript test
    • {{#if desktop}}
  • Open the desktop app: kscript desktop.ks.xml, or package it with kscript app build
    • {{/if}}
  • Check the project: kscript check
  • Change the port, lint rules or app settings in kscript.json
