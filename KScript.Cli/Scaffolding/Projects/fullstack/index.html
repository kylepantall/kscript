Welcome to {{ title }}

{{ title }} is a website with its own JSON API. The Notes page asks the API for its data with @api('/api/notes'), so the pages and any other client (a phone app, a script) share one set of rules.

How it fits together

  • routes/api{{ ext }}: the API's routes, under /api. See them all at /_api.
  • controllers/notes{{ ext }}: the functions that answer them.
    • {{#unless db is none}}
  • models/note{{ ext }}: the Note model, kept in the database (config/config.yaml).
    • {{/unless}}
  • lib/notes-client{{ ext }}: how the pages call the API.
  • tests/: tests for the API and the client. Run them with kscript test.

Next steps

  • Add a page: kscript make page contact
  • Add an API route: kscript make route tags --api
    • {{#unless db is none}}
  • Add a model: kscript make model Tag --fields "name: string"
    • {{/unless}} {{#unless auth}}
  • Add sign-in: kscript make auth
    • {{/unless}}
  • Check the project: kscript check
