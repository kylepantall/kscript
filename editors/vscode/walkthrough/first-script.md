## A script is a list of steps

**New Script** opens a short script you can run straight away:

```kscript
name = "world"
echo "Hello $name!"
```

- `name = "world"` keeps a value under a name.
- `echo` prints a line.
- Inside `"double quotes"`, `$name` is replaced by its value.

Save it with a name ending in `.kscript` when you want to keep it.
