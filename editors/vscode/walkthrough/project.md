## When one file is not enough

A project is a folder with a `kscript.json` file. It keeps your scripts, their tests and the project's settings
together.

**New Project…** asks for a name and a place, then makes the folder for you. In a project you also get:

- **KScript: Run Tests**, and every test listed in the Testing view
- **KScript: Check Project**, which lists every problem in the project
- **KScript: Serve Site**, when the project has pages
