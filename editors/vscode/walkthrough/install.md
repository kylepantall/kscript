## Install the `kscript` command

The editor features come from the `kscript` command, so install it first.

Linux and macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/kylepantall/kscript/master/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/kylepantall/kscript/master/install.ps1 | iex
```

When it is found, the status bar at the bottom shows **✓ KScript**. If it shows a warning, click it.
